Hybrid Object Detection and Segmentation with YOLO and U-Net

This project implements a hybrid deep learning model combining YOLOv1 for object detection and U-Net for semantic segmentation, targeting real-time scene understanding in autonomous driving contexts. Using the CamVid dataset, the model performs both pixel-wise segmentation and bounding box classification across multiple classes, including pedestrians, vehicles, and cyclists. Key contributions include custom preprocessing for bounding box extraction, strategies to address severe class imbalance, and comprehensive evaluation using mAP and IoU metrics. Despite challenges with the detection head, the segmentation model demonstrated strong performance, especially after targeted data augmentation and loss weighting. The work explores the balance between detection and segmentation in shared-backbone architectures.
