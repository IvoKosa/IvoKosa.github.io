Tactile Intelligence for Robotics: Development Journal

Experiment Setup

This experiment will be making use of the franka-emika panda robot and a parallel gripper attachment used to hold the tactile sensor. For this project the sensor in question is a Bioinspired Ciliary sensor (P. Ribeiro et al, 2017). In this case, the sensor is set up to measure the deformation of the artificial cilia hairs, returning 3 signals for each sensor patch in the x, y and z directions. Each sensor has 4 patches and 2 sensors are being used, one on each side of the parallel gripper.

Test Objects

Custom test objects were cast from 5 different silicones each with a different rigidity, alongside a fully 3D printed set, for a total of 6 different material types. For each material 6 different bodies, each with a different texture, were created giving 36 different objects all together. The aim is to teach the model to recognize these different textures and materials with only one grasp from the robot manipulator.

What’s Next

Now that the dataset has been created and the experiment run, the data must now be used to effectively classify both the texture and material. Some initial success has been had with a 1DCNN reaching accuracies of 98%, but other machine and deep learning methods need to be investigated to compare with these results.
